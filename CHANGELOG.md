# Changelog

## 3.0.0 — 2026-10-08

- Reconstructed the project as a single-command FastAPI application with a zero-build frontend.
- Removed runtime sample/test data from the app.
- Added complete clean-slate reset behavior.
- Added `/api/summary` and stronger `/api/meta` metadata.
- Hardened dataset parsing, Startup_ID generation and duplicate handling.
- Improved API error handling and documentation.
- Rebuilt Dashboard, Find, Compare, Data and Watch tabs so each tab has a real empty state and working actions.
- Added live startup detail and compare interactions.
- Kept Swagger, ReDoc and OpenAPI documentation available.
